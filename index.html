GitHub & teknologi

Perkembangan belajar pengembangan web dan perangkat lunak dapat dilihat langsung melalui profil GitHub.

Kunjungi GitHub→

Setiap latihan membantu saya melatih pola pikir perancangan sistem yang terstruktur hingga antarmuka web.

HTML5 & CSS: dipakai untuk menyusun semantik halaman, kontras baca, dan grid yang rapi di desktop maupun ponsel.

.grid-utama {
  display: grid;
  grid-template-columns: repeat(12, 1fr);
}

JavaScript: melatih manipulasi DOM, pengelolaan state sederhana, dan perilaku tombol atau navigasi di browser.

btn.addEventListener('click', () => {
  const on = btn.ariaPressed === 'true';
  btn.ariaPressed = String(!on);
});

TypeScript: membiasakan penulisan tipe data yang jelas saat berlatih menyusun logika API tingkat pemula.

interface Mahasiswa {
  nim: string;
  prodi: 'Sistem Informasi';
}

PHP: mendasari latihan pemrograman berorientasi objek dan pengolahan form pada mata kuliah pemrograman web.

$nama = trim($_POST['nama'] ?? '');
echo htmlspecialchars($nama, ENT_QUOTES);
